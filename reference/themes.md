# Themes

Each theme supplies `base`, `ink`, `accent`, fonts, alignment, easing, duration scale, and motifs. Scene `bg` chooses `base`, `ink`, or `accent`; text uses the higher-contrast base or ink color for the selected background.

`themes.json` holds 70 themes: the 6 originals (`reel`, `pitch`, `infopop`, `kinetik`, `tenang`, `edukasi`) plus 64 ported from the reel-skill style recipes. Ported themes also carry `fx` — default effect presets applied to every scene of a spec that uses the theme, before spec-level and scene-level `fx`.

## Style themes

A ported theme is a *flat* translation of its recipe: palette, type scale, motifs, and default `fx`. Recipes whose rendering technique depends on 3D/WebGL, frame-by-frame texture, or hand-drawn animation lose that technique in the port and keep only colour and type. Named examples: `ember-room` (3D room), `ink-3d-world` (WebGL world), `iso-night` (isometric hand-drawn), `impasto` (paint-stroke texture), `voxel-diorama` (3D voxels), `growing-island` (animated terrain), `frosted-glass` (3D glass panes), `lamp-ink` (lamp-lit ink). Fonts are PostScript names that resolve on this machine; a recipe's declared family is mapped to the closest installed face (Scheherazade New → `Amiri-Regular`, DIN Condensed → `Impact`/`Arial-Black`). No font is bundled with the skill.

## Overrides

A spec can override a theme's `colors` and `fonts`:

```json
{ "theme": "riso-print", "colors": { "accent": "#ff4aa8" }, "fonts": { "display": "Futura-Bold" } }
```

- `colors` keys: `base`, `ink`, `accent`, `muted`, `data`, `sheet`, `marker`. Values are `#rrggbb`.
- `fonts` keys: `display`, `body`, `label`, `quote`, `arabic`. Values are PostScript names.

Both merge over the theme; unknown keys and bad values are validation errors.

## Motifs

| motif | visual effect |
|---|---|
| `slab` | A large ink rectangle slides in behind content. |
| `square` | Uses square corners or square badges rather than rounded shapes. |
| `lineLabel` | Adds a thin line and numbered label above content. |
| `thin` | Uses thinner strokes and outline-style bars or badges. |
| `highlighter` | Places a tilted marker rectangle behind emphasized text. |
| `outline` | Uses ink strokes instead of filled shapes for selected elements. |
| `hardShadow` | Adds a sharp, offset ink drop shadow with zero softness. |
| `underline` | Colors the emphasized range and draws an accent underline. |
| `glow` | Adds layered, low-opacity accent ellipses behind the focal content. |
| `sheet` | Adds a cream sheet rectangle on the base background. |
| `softShadow` | Adds a low-opacity, softened dark drop shadow. |
| `tag` | Makes step badges into paper-tag shapes with a small pin. |
